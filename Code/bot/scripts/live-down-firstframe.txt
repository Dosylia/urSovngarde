# Health climbing back in the down's first frame: the player stays down.
# The game stands a downed player up as soon as health is above zero; the hold must refuse that from the frame the down starts.
#
#   python Tools\VR\live-check.py live-down-firstframe
#   python Tools\VR\live-check.py --expect-fail live-down-firstframe     on a build without the fix: must be RED
#
# The player goes down in a party with this bot standing by, so the server waits (Gameplay:uDownedSeconds).
# Small heals follow the blow back to back, one a frame or so, as a heal still running when the player falls does.
# The ones before the down only lessen a blow far larger than the health; one lands in the frame after the down sets health to zero.
