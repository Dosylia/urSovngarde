# A door used in another game is set here to the state it was left in there, whoever used it.
#
#   python Tools\VR\live-check.py live-door-state
#   python Tools\VR\live-check.py --expect-fail live-door-state     on a build without the fix: must be RED
#
# A game sends a door's activation with the door's state before it. The receiving game replayed the activation with
# its copy of the actor that used the door, so a door opened by an NPC that game has no copy of stayed shut there
# (MGO, 2026-10-22: a door in Helgen's keep, `could not find actor server id 100086`).
# Now a door that does not lead elsewhere is set to the state it ends in over there, with no actor, and setting it
# sends nothing back, so two games cannot pass a door to and fro.
# Here: Helgen keep's door 9B0A5 (not a load door), closed first. The bot sends it opened by an actor no game has,
# the same again, then closed by the bot's own character; last, the game's own player uses it.
log live door state
waitfor connected 45
expect known me
waitfor known other 40
wait 5

log DO god on
log -- the player into Helgen's keep, next to the door, which is closed first
log DO console player.moveto 9B0A5
wait 12
# The bot does not follow on its own: the server takes the player out of its view before it says where she went.
# The server passes a door on only to players in the door's cell.
cell 5DE24
wait 4
# DevBench's Papyrus calls take effect a little after they return, so each one is given a few seconds.
log DO papyrus ObjectReference SetOpen 9B0A5 b:false
wait 6
log DO papyrus ObjectReference IsLocked 9B0A5
log REQUIRE ref 9B0A5 closed
# The checks run while the bot goes on: they are given time before the bot changes the door.
wait 3

log -- opened in another game by an NPC this game has no copy of
activate 9B0A5 by nobody 3
wait 4
log CHECK ref 9B0A5 open
log CHECK logged Door 9B0A5: opened in another game \(by server id 7FFFFF0, not here, from state 3\); set open here from state 3
log CHECK absent could not find actor server id 7FFFFF0

log -- the same opening again: already open here, so nothing is done
activate 9B0A5 by nobody 3
wait 3
log CHECK ref 9B0A5 open
log CHECK logged Door 9B0A5: opened in another game \(by server id 7FFFFF0, not here\); already 1 here

log -- closed in another game by the bot's own character
activate 9B0A5 by me 1
wait 4
log CHECK ref 9B0A5 closed
# Setting a door is not an activation here: nothing goes back out.
expect activations == 0
log CHECK absent Door 9B0A5 \(0:9B0A5\) activated by

log -- this game's player uses the door: that is still sent
log DO papyrus ObjectReference Activate 9B0A5 14 b:false
wait 4
log CHECK ref 9B0A5 open
log CHECK logged Door 9B0A5 \(0:9B0A5\) activated by 14 from state 3
expect activations == 1

log -- locked here, and opened in another game, where it was not locked (a locked door's use is not sent)
log DO papyrus ObjectReference SetOpen 9B0A5 b:false
wait 6
log DO papyrus ObjectReference Lock 9B0A5 b:true b:false
wait 4
log REQUIRE ref 9B0A5 closed
log REQUIRE ref 9B0A5 locked
wait 3
activate 9B0A5 by nobody 3
wait 4
log CHECK ref 9B0A5 open
log CHECK ref 9B0A5 unlocked
log CHECK logged Door 9B0A5: opened in another game \(by server id 7FFFFF0, not here, from state 3\); set open here from state 3, and unlocked: it was locked here
# The unlock may go out as a lock change; the door opening itself still does not.
expect activations == 1

log -- a script blocks the door: this game's player uses it, it stays shut, and nothing goes to the others
log DO papyrus ObjectReference SetOpen 9B0A5 b:false
wait 6
log DO papyrus ObjectReference BlockActivation 9B0A5 b:true
wait 4
log REQUIRE ref 9B0A5 closed
wait 3
log DO papyrus ObjectReference Activate 9B0A5 14 b:false
wait 4
log CHECK ref 9B0A5 closed
log CHECK logged Door 9B0A5 activated by 14, but a script blocks its activation; not sent
expect activations == 1

log -- the blocking script opens the door itself (Activate with default processing only): it opens, and that is sent
log DO papyrus ObjectReference Activate 9B0A5 14 b:true
wait 4
log CHECK ref 9B0A5 open
# The bot's count decides: the earlier step already logged a sent opening of this door.
expect activations == 2
log DO papyrus ObjectReference BlockActivation 9B0A5 b:false
wait 2

wait 3
log CHECK game alive
log DO god off
# The player is left in the keep: a jump out at once has hit Community Shaders' crash at a load (+0x1208c8) in the rig.
# Run this script after a fresh `headless.ps1 up`, which loads the save again.
cell out
wait 2
log done
stop
