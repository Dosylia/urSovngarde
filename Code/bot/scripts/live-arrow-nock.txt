# The arrow on the other player's bow string.
#
#   python Tools\VR\live-check.py live-arrow-nock
#
# "Fix bug where other player cant see when arrow is locked into the bow (always like that)" (Seen and Emma,
# 2026-10-11). In VR the arrow on the string is the game's own attachment, made when the archer's attack state reaches
# 10; nothing carried it. Now the archer's game says when it starts and ends (ArrowNockedRequest), the server passes
# it on, and the other game calls Actor::AttachArrow / DetachArrow on its copy -- by vtable slot, 0xCF and 0xD0 on VR,
# not the 0xCD of Actor.h. A wrong slot is a crash in the receiving game, which is what this run is for first.
#
# This bot is the archer: a hunting bow and iron arrows, its copy made to draw here, then "nock on" and "nock off".
log live arrow nock
waitfor connected 45
expect known me
waitfor known other 40
wait 5

log -- a hunting bow and iron arrows for this bot
additem 13985 1
additem 1397D 20
wait 3
equip 13985 both
equip 1397D
wait 5
log CHECK copy equipped 13985
log CHECK copy equipped 1397D

log -- the copy draws, in front of the headset, in an archer's pose (as live-blade poses its copy): the bow hand out in
log -- front, the string hand back at the chest. Without a VR pose the copy stands with its arms down.
draw on
wait 1
teleport away
wait 6
teleport back
wait 8
infront 120
wait 3
capture other 12
wait 1
handtargets -8 45 110 6 8 118
holdpose on
replay me 2
wait 3
log DO face copy
wait 3
log SHOT bow-drawn of copy

log -- an arrow on the string
nock on
wait 3
log CHECK logged ArrowNocked: \w+ \(server \w+\): arrow put on the string
# The game makes the nocked arrow a moment after AttachArrow; it is laid along the bow once it exists.
wait 4
log CHECK logged ArrowNocked: \w+ arrow laid from the
log CHECK logged ArrowNocked: \w+ arrow laid .* string drawn back
log SHOT arrow-nocked of copy
wait 2

log -- and off again
nock off
wait 3
log CHECK logged ArrowNocked: \w+ \(server \w+\): arrow taken off the string
log SHOT arrow-gone of copy
wait 2
holdpose off
wait 1
log CHECK game alive
log CHECK game inworld
log done
stop
