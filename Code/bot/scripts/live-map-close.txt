# The world map and the skills menu, open unpaused, are taken down on the main thread, the one that draws, never on a
# worker meanwhile.
#
#   python Tools\VR\live-check.py live-map-close        (the rig's server with Gameplay:bUnpausedMenus=true)
#   python Tools\VR\live-check.py --expect-fail live-map-close     on a build without the fix: must be RED
#
# Unpaused, these menus' close was handled on a worker thread while the main thread drew the frame. The close frees the
# menu's 3D, and twice in play (2026-10-28) the main thread then drew one group of render passes forever: a frozen game.
# Paused, as in the game, the close is handled on the main thread. Now a close asked on another thread is held, and the
# main thread makes the menu pause for it and posts it itself.
# Here each menu opens unpaused and closes six times: three by the game's own Cancel (Escape), three by a bare hide.
log live map close
waitfor connected 45
expect known me
waitfor known other 40
wait 5
stay

log -- the map, closed by the game's Cancel (Escape), three times
log DO menu open MapMenu
log DO sleep 3
log DO key escape 200
wait 8
log REQUIRE logged Menu opened while connected: MapMenu \(runs unpaused\)
log DO menu open MapMenu
log DO sleep 3
log DO key escape 200
wait 8
log DO menu open MapMenu
log DO sleep 3
log DO key escape 200
wait 8

log -- the map, closed by a bare hide, three times
log DO menu 3 MapMenu
wait 7
log DO menu 3 MapMenu
wait 7
log DO menu 3 MapMenu
wait 7

log -- the skills menu, the same six times
log DO menu open StatsMenu
log DO sleep 3
log DO key escape 200
wait 8
log REQUIRE logged Menu opened while connected: StatsMenu \(runs unpaused\)
log DO menu open StatsMenu
log DO sleep 3
log DO key escape 200
wait 8
log DO menu open StatsMenu
log DO sleep 3
log DO key escape 200
wait 8
log DO menu 3 StatsMenu
wait 7
log DO menu 3 StatsMenu
wait 7
log DO menu 3 StatsMenu
wait 7

log CHECK atleast 6 Map menu: hide handled on thread \d+ \(the main thread\)
log CHECK absent Map menu: hide handled on thread \d+ \(not the main thread
log CHECK atleast 6 Skills menu: hide handled on thread \d+ \(the main thread\)
log CHECK absent Skills menu: hide handled on thread \d+ \(not the main thread
log CHECK absent FreezeWatchdog: no frame of ours
log CHECK game alive
wait 3
log done
stop
