# Against a real game: the other players as icons on the world map.
#
#   python Tools\VR\live-check.py live-markers
#
# While the bot's body is in the game it has no marker; five cells away the body unloads and a map icon follows it.
# Map markers are SkyrimTogether.esp's 5040 to 505F, never on the compass.
# The DO papyrus lines name the esp at load index 8A and print where map marker 1 stands.
log live markers
waitfor connected 45
waitfor known other 40
wait 8

log CHECK logged Player markers: forms found
log CHECK absent Player markers: .*(missing|not found|no map marker data)
wait 2

log -- near: its body is in the game, so no marker
log CHECK absent Player markers: \w+ follows player
wait 2

log -- walking five cells away: its body leaves the game, a map icon follows it
walk rel 20000 0 3000
wait 14
log CHECK logged Player markers: \w+50[45][0-9A-F] follows player
log DO papyrus ObjectReference GetPositionX 8A005040
log DO papyrus ObjectReference GetParentCell 8A005040
wait 2

log -- back near: the icon is put away
walk rel -20000 0 3000
wait 14
log CHECK logged Player markers: \w+50[45][0-9A-F] put away
wait 2
log done
stop
