# Rolls a world object it put down, the way a pushed cart rolls downhill, while the other bot enters the cell again meanwhile.
#
#   powershell -ExecutionPolicy Bypass -File Tools\VR\run-bot-tests.ps1 -Pair objectroll
#
# The server sends a player what it remembers of an object each time that player changes cell.
# Sent while the object rolled, its last resting place stopped it and put it back up the hill in its mover's game.
# Its own interior, so it can share a run with the other pairs.

log objectroll actor
waitfor connected 45
collect spawn
record objectroll actor

waitfor players >= 1 30
expect known me
waitfor known other 40

log going inside
wait 2
cell 2B4A1
waitfor samecell other 40
wait 3

log putting the plate down
moveobject 92D04 0 0 0 rest
wait 3
