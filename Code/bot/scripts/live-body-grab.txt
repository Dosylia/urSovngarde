# A dead body this bot owns, grabbed by the player's HIGGS hand and dragged: the player's game must ask for it and
# send its bones, so the bot's side (the other player) sees it move.
#
#   python Tools\VR\live-check.py live-body-grab
#
# A body dragged by a player whose game does not own it must move in the game that owns it.
# The dragging game's log shows the hand-off as "is being moved here; asking for it", "BodyGrabDiag" or "no hand of this player's is on it".
# live-body-owner covers the other half (the owner dragging it past).
log live body grab
waitfor connected 45
collect spawn health death ownership
expect known me
waitfor known other 40
wait 5

log -- a bear of this bot's, killed
npc temp 23A8A
waitfor owned == 1 20
wait 8
npclife dead 0
wait 6
log CHECK npc dead

log -- the player takes it with the right hand and walks off with it: thirty steps of 15 units
log DO papyrus Actor SheatheWeapon 14
wait 3
log DO grab npc right
wait 4
log DO mark body npc
log DO walk 0 15 0 30
wait 10
# The body itself must have come along (its pelvis, where it is drawn), not only the log lines about it.
log CHECK moved body atleast 100
log CHECK near body 250
log CHECK logged Body \w+ \(server id \w+\) is being moved here; asking for it
log CHECK logged VRBodySync: body \w+ is being moved here
log CHECK game alive
wait 3
log done
stop
