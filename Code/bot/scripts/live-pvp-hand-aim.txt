#
#   python Tools\VR\live-pvp-hand.py
#
# That driver starts this script, and holds the trigger with a held spell (Flames unless told otherwise) in the hands aimed at the bot, through the virtual controllers.
# So the spell is the game's own, from the hand, turned by the spell mods as in play.
# The bot reads the aim that arrives with the pose, and says how far it is from the way to the bot.
# This checks the sending half only: the bot has no second game to show the spell in.
# A run counts only when (REQUIRE): the spell hit the bot's copy in this game.

infront 200
wait 3

log CHECK bot logged Spell aim of the player at

log CHECK game alive
