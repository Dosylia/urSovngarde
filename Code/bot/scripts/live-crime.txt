# Does the crime alarm guard fire, and does the game survive a crime while connected?
#
#   python Tools\VR\live-check.py live-crime
#
# The crime alarm (Actor::StealAlarm) runs behind a guard, which logs only a failed run (`Crime alarm walked a null actor`).
# Here the player "steals" a horse at Windhelm's docks, where there are people to see it, through the game's own SendStealAlarm.
# The alarm runs when the witnesses report it: the player's bounty with Eastmarch (CrimeFactionEastmarch, 267E3) goes up.
# The bounty is real in this session and gone with it: nothing is saved.
log live crime
waitfor connected 45
expect known me
waitfor known other 40
wait 5
stay

log DO god on
wait 3
log -- to Windhelm's docks, where there are people to see a crime
log DO papyrus ObjectReference MoveTo 14 35E6E f:0 f:0 f:0 b:false
wait 40
log CHECK game alive

log -- the player steals a horse, as far as the witnesses are concerned
log CHECK bounty 267E3 mark
wait 2
log DO papyrus ObjectReference SendStealAlarm 9848C 14
wait 6
log CHECK bounty 267E3 raised
log CHECK absent Crime alarm walked a null actor
log CHECK game alive
wait 3

log -- back
log DO papyrus ObjectReference MoveTo 14 4AFD9 f:-32 f:-911 f:262 b:false
wait 40
log CHECK game alive
log DO god off
wait 3
log done
stop
