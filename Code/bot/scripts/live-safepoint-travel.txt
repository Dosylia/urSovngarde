# A safe point after each loading screen: console travel shows one, and the game would autosave where it ends.
#
#   python Tools\VR\live-check.py live-safepoint-travel
#
# The client counts loading screens as the game queues them (UI::LoadingScreensQueued): its own update may not run while
# one shows, and watching for the menu from there missed every travel in the rig. God mode keeps the player out of a fight,
# which would leave the last safe point in place.
log live safepoint travel
waitfor connected 45
expect known me
waitfor known other 40
wait 5
log DO god on
wait 3

log -- travel elsewhere: a safe point where the player arrives
log DO papyrus ObjectReference MoveTo 14 35E6E f:0 f:0 f:0 b:false
wait 40
log CHECK logged PlayerService: safe point in cell \w+ '.*' at \(1[34]\d{4}, 3\d{4},

log -- and back
log DO papyrus ObjectReference MoveTo 14 4AFD9 f:-32 f:-911 f:262 b:false
wait 40
log CHECK logged PlayerService: safe point in cell \w+ '.*' at \(1[34]\d{4}, -3\d{4},
log DO god off
wait 3
log CHECK game alive
log done
stop
