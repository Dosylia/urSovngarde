# Another player's follower taken outdoors leaves this player's interior, and this game's own reference stays as it was.
#
#   python Tools\VR\live-check.py live-follower-left
#   python Tools\VR\live-check.py --expect-fail live-follower-left     on a build without the fix: must be RED
#
# One player takes a follower out of an inn while the other stays inside: the one inside kept a frozen copy of her.
# Now the copy goes with her, and this game's own reference, never moved, is back in the inn as this game's own NPC.
# Here the game's player is in the inn with Lydia, the bot comes in, takes her as its follower, and goes out with her.
# The player is left in the inn: run this script after a fresh `headless.ps1 up`, which loads the save again.
# It is moved there by Papyrus, beside the innkeeper: console travel from a worker thread has crashed the rig's draw.
log live follower left
waitfor connected 45
collect ownership party
expect known me
waitfor known other 40
ownership accept
wait 5

log -- the player in the inn, Lydia beside it and no longer its teammate
log DO papyrus ObjectReference MoveTo 14 13486 f:60 f:0 f:0 b:false
wait 14
cell 133C6
wait 3
log DO papyrus ObjectReference MoveTo A2C94 14 f:100 f:0 f:0 b:false
log DO papyrus Actor SetActorValue A2C94 s:WaitingForPlayer f:1
log DO papyrus Actor SetPlayerTeammate A2C94 b:false b:false
waitfor known ref:A2C94 40
wait 5
log -- the bot takes her
claim ref:A2C94 follower
stay
wait 6
log REQUIRE ref A2C94 cell same
log CHECK ref A2C94 disabled
# The driver reads the checks as they are logged, so the bot waits before it changes what they read.
wait 2

log -- the bot goes outdoors with her
cell out
npcmove 0 0 0
wait 8
log CHECK ref A2C94 cell same
log CHECK ref A2C94 enabled
log CHECK logged Follower: A2C94 \(server id \w+\) is player \w+'s, far from here; this game's own reference is left as it is
log CHECK game alive
wait 2
log done
stop
